# Integration

The Integration module provides specialized adapters and wrappers that allow GianaUtils to seamlessly interface with popular third-party Unity assets. These are optional but highly recommended if you are already using these assets in your project.

## Included Integrations

### DOTween
*   **`DOTweenMenuAnimator`**: A `MenuAnimatorBase` implementation that leverages DOTween for smooth, customizable UI menu animations.

### Feel (MoreMountains)
*   **`FeelUITransition`**: An `IUITransition` implementation that triggers MMFeedbacks (from the Feel asset) to create juicy and complex UI transitions (Show/Hide) visually configurable in the inspector.
